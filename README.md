### Projetos em destaque

#### [Giro Rápido](https://github.com/menesesthdev) — Plataforma SaaS para Lavanderias
Plataforma SaaS multi-tenant para franqueados operarem lavanderias self-service 100% autônomas: o cliente se identifica no totem, escolhe a máquina e inicia o ciclo, com débito automático de créditos.

`.NET 10` · `EF Core 10` · `PostgreSQL 16` · `RabbitMQ (MassTransit)` · `React 19` · `TypeScript` · `Docker`

- Back-end em Clean Architecture (Domain, Application, Infrastructure, API) com autenticação via JWT Bearer
- Arquitetura orientada a eventos com RabbitMQ/MassTransit para o ciclo das máquinas
- Front-end React 19 feature-based com três interfaces: totem touch, painel do franqueado e área do cliente

#### [AzurePrep](https://github.com/menesesthdev) — Simulado do exame AZ-900
Simulado do exame Microsoft Azure Fundamentals que replica a experiência real de prova — timer, navegação linear, tela de revisão e score report — com banco de questões 100% autoral, escrito a partir do Skills Measured oficial.

`.NET 10` · `ASP.NET Core MVC` · `EF Core` · `SQLite` · `xUnit` · `Docker`

- Clean Architecture com DDD leve e testes unitários (xUnit) em Domain e Application desde a primeira etapa
- Autenticação própria (sem ASP.NET Identity): cookies, OAuth/OIDC (Google, GitHub, LinkedIn) e hash PBKDF2-HMAC-SHA256
- Proteção contra força bruta em duas camadas e geração de QR Code Pix no servidor, validada contra o manual do BR Code do Banco Central
